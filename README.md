# QAIS HOST — PS4

بوابة ويب مستقلة تعرض إصدار النظام المكتشف من متصفح PS4 وتوجّه إلى الصفحة المنشورة المطابقة للإصدارين 11.00 و14.00.

## الرابط بعد تفعيل GitHub Pages

https://qais-mp7.github.io/qais/

## الإصدارات

- **11.00** → [RAWGAME4](https://rawgame4.github.io/) — صفحة المستضيف الأصلية تختار السلسلة بحسب معلومات متصفح الجهاز، وتعرض تعليمات التخزين المؤقت والتشغيل.
- **14.00** → [Afterglow](https://well0nez.github.io/afterglow-web/) — صفحة المشروع المنشورة تدعم 14.00 وتعرض خيارات HEN وGoldHEN.

هذه البوابة موجّه فقط؛ لا تستضيف ملفات الاستغلال ولا تعدّلها. تنقل المستخدم إلى صفحات المشاريع الأصلية. قد تفشل المحاولات أو يتوقف المتصفح أو يعيد الجهاز التشغيل؛ لا يوجد ضمان لنجاح كل محاولة.

## الكشف

- يتحقق من أن الصفحة مفتوحة في متصفح PS4.
- يقرأ رقم Firmware من User-Agent.
- يوجّه فقط 11.00 و14.00.
- لا يخمّن الإصدارات غير المعروفة، ويتيح إلغاء التحويل التلقائي.

## النشر

المستودع مجهّز بملف GitHub Actions في `.github/workflows/pages.yml`. بعد رفع التغييرات، يجهّز سير العمل GitHub Pages وينشر محتويات الفرع `main`. راجع تبويب **Actions** للتأكد من اكتمال النشر.

## الحقوق

واجهة QAIS HOST مستقلة. ملفات وأدوات المشاريع المشار إليها تبقى على مستودعات أصحابها وتخضع لتراخيصهم وشروطهم. لا يعاد توزيعها هنا.
